# BeatMind Reference-to-Track Guide

## Pick the Goal

- A whole-song template: review the full reference, its stems and section timing. Choose Whole track in Listening, not a short vocal excerpt.
- One sound or transition: choose Excerpt, a start time, a 5-30 second length and the relevant audio layer.
- A plan without paid AI listening: review stems and timing, then use a manual creative brief. AI listening is optional; provider permission is never assumed.

The reference tabs show saved progress and pending prerequisites. You can revisit any tab. Navigation does not approve sounds, generate music or change the Ableton set.

## 1. Stems

The reference's audio files are saved after successful processing. Saving your creative choices is a separate step.

The on-screen Next step action follows your current review: the next undecided layer, listening confirmation, saving choices, then Timing. It moves focus without choosing or confirming on your behalf. A missing save receipt instead offers Check save status; a saved review needing attention returns to the relevant layer.

1. Audition each stem using its play button. The adjacent download button saves its WAV to your computer.
2. Choose Use as reference, Exclude from my track or Separation needs work for each of the four groups.
3. Confirm that you listened, then select Save stem review.
4. A complete accepted review exposes Continue to timing. Needs-work choices can be saved but do not approve a template.

Hint: the current production separator outputs drums, bass, vocals and other instruments. Drum components remain combined. These are estimates with possible bleed, not the artist's original studio files. Detailed drum evaluation files generated locally are not additional production template inputs yet.

## 2. Timing

1. Review source BPM, meter and proposed section boundaries.
2. Cue each section to check its beginning. Split or merge sections as necessary, and edit names and boundaries.
3. Confirm that you reviewed the timing, then select Confirm timing map.
4. Continue to listening, or open Template for manual planning.

Hint: automatic tempo, key and structural estimates are not guaranteed exact. Confirmation is your review decision. Keep all intervals continuous and within the reference duration. Following reference timing preserves the confirmed seconds, including fractional bars.

## 3. Listening

1. Choose Whole track for overall arrangement and energy, or Excerpt for a specific sound.
2. Select Allow audio analysis only when you agree to send the stated audio and intent to OpenAI. Charges may apply. This permission is separate from upload permission.
3. Enter a listening brief, for example: "Focus on the warm bass groove, restrained drums and gradual build. I want original sounds with a similar energy curve."
4. Select Send listening request. The submitted intent and processing status appear below.
5. Review the listening notes, then Continue to template. Use a manual brief is available without submitting audio.

Hint: "What do you want from this reference?" is an analysis brief, not an Ableton production command. Writing "make a template" there does not itself import stems or create a Live Set. An excerpt does not establish whole-song coverage. AI musical descriptions remain interpretations, not verified original effect chains or notes.

If completion is unconfirmed, use Check listening status rather than sending again. A successful server receipt remains saved even if a subsequent status refresh fails.

## 4. Template

Stem review and timing confirmation are prerequisites. The page links back to whichever review is missing.

1. Taste: describe what to retain and avoid.
2. Direction: name the track and choose style, mood, key preference and feel.
3. Sounds: choose planned roles, desired timbres and any required pack or instrument. Proposed effects remain adjustable suggestions.
4. Sections: review the ordered sections and their direction. Follow confirmed reference timing or choose custom bar lengths.
5. Save template draft, or separately consent to a paid template suggestion.
6. Review and Approve planning brief. Open Ableton after approval is selected by default and can be turned off.
7. Download timing guide and blueprint, or Plan first part in chat.

Hint: approval saves a planning blueprint. It is not proof of an imported arrangement, verified instrument inventory or completed musical parts. Opening Ableton only activates the application; it does not overwrite a set or import the blueprint. Chat remains the production handoff for building original parts.

If Bridge is disconnected when opening is requested, the dashboard shows a pending Ableton launch. Open Bridge, sign in and connect; activation runs once after the connection is observed while the dashboard remains open. Cancel pending Ableton launch cancels that wait. An unsuccessful or unconfirmed launch is not labeled successful.

## 5. Compare

1. After a part is built and an actual Ableton audition is captured, choose that recording.
2. Choose the reference layer and matching start positions, with a comparison length of 2-16 seconds that fits both files.
3. Select Compare sounds, then audition A and B.
4. Review measured level, crest, spectrum and stereo differences. Return to music chat to request changes or the next original part.

Hint: no recording means there is nothing to compare yet. A/B previews are level-matched for comparison; the measurements are not a quality score, originality guarantee or proof that effects match the source. Comparing audio does not modify Ableton.

## Bridge and Ableton Controls

The dashboard connection bar stays visible across its views. Bridge opens the installed BeatMind Bridge window even when it is already connected. The browser may request permission to open the external application. Installation remains optional when the bridge is disconnected.

Ableton requests application activation through your account's connected Bridge. It does not save, discard, create or select a Live Set. The displayed outcome comes from the Bridge response. You can retry an explicit failure after resolving its message; an uncertain result requires checking the app first.

In music chat, Choose Live Set provides separate explicit save/new/inspect/confirm actions. Finish macOS save or permission dialogs yourself. Then build one original part at a time, review its actual audition, refine effects, and approve it before continuing. The reference workflow alone is not a finished song.
