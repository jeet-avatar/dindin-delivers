# Inventory Management and WMS

## Overview

NetSuite Inventory Management tracks item quantities across locations, supports
lot and serial number traceability, and integrates with the Warehouse Management
System (WMS) for bin-level inventory control.

---

## Inventory Feature Setup

Navigate: Setup > Company > Enable Features > Items & Inventory tab

Key features to enable:
- **Multi-Location Inventory** — track inventory per location/warehouse
- **Bins** — bin-level tracking within a location
- **Lot Tracking** — group items by lot (batch) numbers
- **Serialized Inventory** — track individual unit serial numbers
- **Warehouse Management System (WMS)** — advanced warehouse operations

---

## Item Configuration

### Lot-Tracked Items

```javascript
define(['N/record'], function(record) {
    var item = record.load({ type: record.Type.INVENTORY_ITEM, id: 456 });

    // Check if lot-tracked
    var isLot = item.getValue({ fieldId: 'islotitem' }); // true/false

    // Check if serialized
    var isSerial = item.getValue({ fieldId: 'isserialized' }); // true/false
});
```

**Configuration on Item record:**
- Lot Item field: `isLotItem = true`
- Serialized field: `isSerialized = true`

## Inventory Detail Sublist

The `inventorydetail` sublist appears on transactions that move lot/serial items:
- Item Fulfillment (shipping)
- Item Receipt (receiving)
- Inventory Adjustment
- Transfer Order

```javascript
define(['N/record'], function(record) {
    var itemFulfillment = record.load({ type: record.Type.ITEM_FULFILLMENT, id: 789 });

    // Get inventory detail for line 0
    var invDetail = itemFulfillment.getSubrecord({
        sublistId: 'item',
        fieldId: 'inventorydetail',
        line: 0
    });

    // Assign lot number
    invDetail.selectNewLine({ sublistId: 'inventoryassignment' });
    invDetail.setCurrentSublistValue({
        sublistId: 'inventoryassignment',
        fieldId: 'issueinventorynumber',
        value: 'LOT-2024-001'  // Lot number text
    });
    invDetail.setCurrentSublistValue({
        sublistId: 'inventoryassignment',
        fieldId: 'quantity',
        value: 50
    });
    invDetail.commitLine({ sublistId: 'inventoryassignment' });

    itemFulfillment.save();
});
```

## Bin Locations

Bins subdivide a location into physical storage areas (shelves, rows, aisles).

### Enabling Bins

Navigate: Setup > Inventory > Set Up Locations > Edit a Location > check "Use Bins"

### Bin-Level Tracking

Items can be assigned to specific bins:
- **Bin putaway:** assign received items to bins
- **Bin picking:** specify which bin to pick from during fulfillment

```javascript
// On Item Receipt — assign to bin
var receipt = record.load({ type: record.Type.ITEM_RECEIPT, id: 100 });

receipt.selectLine({ sublistId: 'item', line: 0 });
// Set bin via inventory detail subrecord
var invDetail = receipt.getSubrecord({
    sublistId: 'item',
    fieldId: 'inventorydetail',
    line: 0
});
invDetail.selectNewLine({ sublistId: 'inventoryassignment' });
invDetail.setCurrentSublistValue({
    sublistId: 'inventoryassignment',
    fieldId: 'binnumber',
    value: 25 // Bin internal ID
});
invDetail.setCurrentSublistValue({
    sublistId: 'inventoryassignment',
    fieldId: 'quantity',
    value: 100
});
invDetail.commitLine({ sublistId: 'inventoryassignment' });
```

## Transfer Orders

Transfer Orders move inventory between locations:

```javascript
define(['N/record'], function(record) {
    var to = record.create({ type: record.Type.TRANSFER_ORDER });
    to.setValue({ fieldId: 'transferlocation', value: 5 }); // Source location
    to.setValue({ fieldId: 'location', value: 8 });          // Destination location
    to.setValue({ fieldId: 'memo', value: 'Replenishment from main warehouse' });

    to.selectNewLine({ sublistId: 'item' });
    to.setCurrentSublistValue({ sublistId: 'item', fieldId: 'item', value: 456 });
    to.setCurrentSublistValue({ sublistId: 'item', fieldId: 'quantity', value: 200 });
    to.commitLine({ sublistId: 'item' });

    var transferOrderId = to.save();
});
```

**Transfer Order process:**
1. Create Transfer Order (status: Pending Fulfillment)
2. Create Item Fulfillment from TO (items leave source)
3. Create Item Receipt from TO (items arrive at destination)

## WMS Setup

Navigate: Setup > Inventory > Enable WMS

WMS provides:
- **Directed putaway:** system assigns bins based on item attributes and bin rules
- **Directed picking:** pick lists generated by optimal path
- **Wave picking:** batch multiple orders into a picking wave
- **RF device support:** scanner-enabled warehouse operations

### WMS Configuration

1. Enable WMS: Setup > Inventory > Warehouse Management Setup
2. Configure locations as WMS-enabled
3. Set bin types (bulk, active pick, overflow)
4. Configure putaway rules: item category, size, weight → bin zone
5. Configure pick strategies: FIFO, FEFO (First Expired First Out), LIFO

## Inventory Adjustments

```javascript
define(['N/record'], function(record) {
    var adj = record.create({ type: record.Type.INVENTORY_ADJUSTMENT });
    adj.setValue({ fieldId: 'account', value: 150 }); // Adjustment account

    adj.selectNewLine({ sublistId: 'inventory' });
    adj.setCurrentSublistValue({ sublistId: 'inventory', fieldId: 'item', value: 456 });
    adj.setCurrentSublistValue({ sublistId: 'inventory', fieldId: 'location', value: 5 });
    adj.setCurrentSublistValue({ sublistId: 'inventory', fieldId: 'adjustqtyby', value: -5 }); // Shrinkage
    adj.commitLine({ sublistId: 'inventory' });

    adj.save();
});
```

## Demand Planning and Reorder

Set reorder points on items:
1. Item record > Purchasing/Inventory tab
2. Set: Reorder Point, Preferred Stock Level, Purchase Description
3. Navigate: Lists > Supply > Reorder Items — shows items below reorder point
4. Suggest PO creation for each item

**Supply Planning:** Transactions > Demand Planning > Generate Purchase Orders
