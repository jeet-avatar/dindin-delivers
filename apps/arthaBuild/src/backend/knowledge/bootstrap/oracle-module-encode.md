# N/encode Module

Use the N/encode module to convert a string to another type of encoding. This module exposes string encoding and decoding functionality.

---|---|---|---|---  
Method |  [encode.convert(options)](section_4369851165.html) |  string |  Server scripts |  Converts a string to another type of encoding and returns the re-encoded string.  
Enum |  [encode.Encoding](section_4369865177.html) |  enum |  Server scripts |  Holds the string values for the supported character set encoding.
