# NetSuite Navigation Paths — Complete Reference

This document provides exact menu navigation paths for common NetSuite operations.
Use these paths to direct users to the correct location in the UI.

---

## SuiteCloud / Development

| What You Want To Do                  | Navigation Path                                                        |
|--------------------------------------|------------------------------------------------------------------------|
| View all Scripts                     | Setup > Customization > Scripts > Scripts                              |
| View Script Deployments              | Setup > Customization > Scripts > Script Deployments                   |
| View Script Execution Log            | Setup > Customization > Scripts > Script Execution Log                 |
| Debug a script                       | Setup > Log and Diagnostics > Script Debugger                         |
| View all Workflows                   | Setup > Customization > Workflow > Workflows                           |
| Create a new Workflow                | Setup > Customization > Workflow > Workflows > New                     |
| View Workflow Execution Log          | Setup > Log and Diagnostics > Workflow Execution Log                  |
| Create a Custom Record Type          | Setup > Customization > Lists, Records & Fields > Record Types > New  |
| Create Transaction Body Field        | Setup > Customization > Lists, Records & Fields > Transaction Body Fields > New |
| Create Transaction Column Field      | Setup > Customization > Lists, Records & Fields > Transaction Column Fields > New |
| Create Entity (Customer) Field       | Setup > Customization > Lists, Records & Fields > Entity Fields > New |
| Create Item Field                    | Setup > Customization > Lists, Records & Fields > Item Fields > New   |
| Create Custom List                   | Setup > Customization > Lists, Records & Fields > Custom Lists > New  |
| View all Integrations                | Setup > Integration > Manage Integrations                              |
| Create new Integration               | Setup > Integration > Manage Integrations > New                        |
| View Access Tokens                   | Setup > Security > Access Tokens                                       |
| Create new Access Token              | Setup > Security > Access Tokens > New                                 |
| Enable Features (SuiteCloud, TBA)    | Setup > Company > Enable Features                                      |
| View SuiteScript API Reference       | Customization > SuiteCloud > SuiteScript > API Version 2.x            |
| View Execution Log (scripts)         | SuiteCloud > Log and Diagnostics > Execution Log                       |
