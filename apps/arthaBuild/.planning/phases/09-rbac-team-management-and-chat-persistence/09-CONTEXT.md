# Phase 9 Context — RBAC, Team Management and Chat Persistence

## User Design Decisions

- Phase 9 should include a **full dashboard** for logged-in users
- Phase 9 should include a **complete admin view** — admin can see all team chats, manage team members, view platform activity
- Admin panel is NOT a separate future phase — it is part of Phase 9

## Scope Clarification

Beyond what is listed in ROADMAP.md, Phase 9 includes:
- A proper user dashboard (post-login landing page showing chat history, quick actions)
- A full admin panel with: all team chats, team member management, invite flow
- The admin view is the primary admin interface for the application

## What This Means for Planning

- Plans should include both the backend API work AND the frontend dashboard/admin UI
- The admin panel UI should be built in this phase, not deferred
- User dashboard should be a separate plan from the admin panel
