    @pytest.mark.asyncio
    async def test_tba_session_isolation(client):
        """Critical: user A's TBA creds must not be accessible by user B."""
        from session_store import set_session_creds, get_session_creds, NetSuiteCreds, clear_session_creds
        from datetime import datetime, timezone

        # Set creds for user 1
        creds_1 = NetSuiteCreds("ACCT1", "TK1", "TS1", "CK1", "CS1", datetime.now(timezone.utc))

        assert get_session_creds(2) is None

        # User 1 creds are accessible
        assert get_session_creds(1) is not None
        assert get_session_creds(1).account_id == "ACCT1"

        # Cleanup
        clear_session_creds(1)
        assert get_session_creds(1) is None

  <action>
    **Case AB-SEC-001: Why rate limit login?**
    Q: What attack does rate limiting on /api/auth/login prevent?
    A: Brute-force credential stuffing. Without rate limiting, an attacker can try
       thousands of passwords per second. Rate limiting to 10/minute per IP means
       300 attempts in 30 minutes — combined with account lockout at 5 attempts,
       this makes automated attacks infeasible.

    Install slowapi:
    ```bash
    source .../venv/bin/activate
    pip install slowapi
    ```

    Add to rawapi.py:
    ```python
    from slowapi import Limiter, _rate_limit_exceeded_handler
    from slowapi.util import get_remote_address
    from slowapi.errors import RateLimitExceeded

    limiter = Limiter(key_func=get_remote_address)
    app.state.limiter = limiter
    app.add_exception_handler(RateLimitExceeded, _rate_limit_exceeded_handler)
    ```

    Add to auth router login endpoint:
    ```python
    from slowapi import Limiter
    from slowapi.util import get_remote_address

    @router.post("/login")
    @limiter.limit("10/minute")
    async def login(request: Request, payload: LoginRequest, db: AsyncSession = Depends(get_db)):
        ...
    ```

    Also add to /api/auth/forgot-password:
    ```python
    @router.post("/forgot-password")
    @limiter.limit("5/minute")
    async def forgot_password(request: Request, ...):
    ```

    Add slowapi to requirements.txt.
  </action>
