## Wave 4 — Domain Setup: artha.build → Staging

### Task 4.1 — Gather staging server info
- **Action:** Check docker-compose.yml and nginx config to determine what IP/URL staging runs on.
- Staging URL format will be the public IP or domain where `docker-compose up` is running.

### Task 4.2 — DNS configuration for artha.build
**Domain registrar:** Determine where artha.build is registered (Namecheap, GoDaddy, Cloudflare, etc.)
- **Option A — Cloudflare DNS (recommended):**
  ```
  A     artha.build        <staging-server-ip>    Proxied: ON
  A     www.artha.build    <staging-server-ip>    Proxied: ON
  ```
- **Option B — Direct A record (no proxy):**
  ```
  A     @       <staging-server-ip>    TTL: 300
  A     www     <staging-server-ip>    TTL: 300
  ```

### Task 4.3 — Update nginx.prod.conf server_name
- **File:** `nginx/nginx.prod.conf`
- **Change:** `server_name _;` → `server_name artha.build www.artha.build;`
- **Verify:** `grep server_name nginx/nginx.prod.conf` shows artha.build.

### Task 4.4 — Update CORS and backend config for artha.build
- **File:** `src/backend/.env` (staging)
- **Update:**
  ```
  FRONTEND_BASE_URL=https://artha.build
  ALLOWED_ORIGINS=https://artha.build,https://www.artha.build
  APP_BASE_URL=https://artha.build
  ```
- **Verify:** `grep "artha.build" src/backend/.env` shows correct URLs.

### Task 4.5 — SSL certificate for artha.build
- **Option A — Let's Encrypt (Certbot, free):**
  ```bash
  certbot --nginx -d artha.build -d www.artha.build
  ```
- **Option B — Self-signed (dev/testing only):**
  ```bash
  openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
    -keyout nginx/ssl/artha.build.key \
    -out nginx/ssl/artha.build.crt \
    -subj "/CN=artha.build"
  ```
- Update `nginx/nginx.prod.conf` ssl_certificate paths accordingly.

**Note:** If staging is on Hostinger or similar shared hosting, skip Docker and instead:
- Upload `dist/` (frontend build) to public_html
- Point backend subdomain (api.artha.build) to the server running FastAPI
- This is: `/gsd:discuss-phase` territory — requires user input on hosting setup.
