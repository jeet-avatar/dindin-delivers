## Wave 3 — Auth & Response Fixes (CASE-005, 006, 024)

### Task 3.1 — Fix user_type hardcoded to 'Administrator' (CASE-005)
- **File:** `src/backend/routers/auth.py`
- **Find:** The TokenResponse or login return dict where `user_type` is set.
- **Change:** Replace hardcoded `"Administrator"` with `user.role` (or map: admin→"Administrator", user→"User")
- **Verify:** Login as a regular user → response `user_type` is not "Administrator".

### Task 3.2 — Add role field to refresh token response (CASE-024)
- **File:** `src/backend/routers/auth.py` (refresh endpoint)
- **Why:** Login response includes `role` but refresh response does not — inconsistent.
- **Change:** Add `"role": user.role` to the refresh endpoint return dict.
- **Verify:** `grep -A20 "def refresh" src/backend/routers/auth.py` shows `role` in return.

### Task 3.3 — Add COLLATE NOCASE index to User.email (CASE-006)
- **File:** `src/backend/models.py` — User.email column definition
- **Why:** login() normalizes email to lowercase but the DB column has no case-insensitive index, so lookups on mixed-case emails in the DB could fail.
- **Change:** Add `collation='NOCASE'` to the email column: `Column(String, unique=True, nullable=False, index=True, sqlite_extra_kwargs={"collation": "NOCASE"})` — or create a new Alembic migration that recreates index with COLLATE NOCASE.
- **Migration:** Create `alembic/versions/e1f2g3h4i5j6_add_email_nocase_collation.py`
- **Verify:** `alembic upgrade head` succeeds, migration history shows new revision.
