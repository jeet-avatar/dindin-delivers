## Chunk 4: Database Migration

### Task 7: Run Alembic migration for Q285 (script_generations table)

This creates the `script_generations` table used for free-tier quota tracking.

- [ ] **Step 1: Identify how to run Alembic inside Docker**

```bash
# Go back to ArthaBuild root (where docker-compose.yml is)
cd ~/arthaBuild  # adjust if different

# List running containers
docker-compose ps
```

Expected: `backend` container is listed as running/healthy.

- [ ] **Step 2: Run migration inside the backend container**

```bash
docker-compose exec backend alembic upgrade head
```

Expected output:
```
INFO  [alembic.runtime.migration] Context impl SQLiteImpl.
INFO  [alembic.runtime.migration] Will assume non-transactional DDL.
INFO  [alembic.runtime.migration] Running upgrade ... -> 22a_free_tier_script_counter, Add script_generations table for free-tier quota
```

> If output says `INFO  [alembic.runtime.migration] Running upgrade d5e6... -> 22a_...` — that's correct, it chains from the last migration.

- [ ] **Step 3: Verify table was created**

```bash
docker-compose exec backend python3 -c "
from database import engine
import asyncio, sqlalchemy as sa

async def check():
    async with engine.connect() as conn:
        result = await conn.execute(sa.text(\"SELECT name FROM sqlite_master WHERE type='table' AND name='script_generations'\"))
        row = result.fetchone()
        print('Table exists:', row is not None)

asyncio.run(check())
"
```

Expected: `Table exists: True`
