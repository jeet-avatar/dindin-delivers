# Din Din Delivers

A food delivery application that connects customers with local restaurants.

## Overview

Din Din Delivers is a platform that enables:
- **Customers** to browse restaurants, view menus, and place food orders
- **Restaurants** to manage their menus and receive orders
- **Delivery drivers** to accept and fulfill delivery requests

## Features

- Restaurant discovery and search
- Menu browsing and ordering
- Order tracking
- Delivery management

## Getting Started

### Prerequisites

- Node.js 18 or higher
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/jeet-avatar/dindin-delivers.git

# Navigate to the project directory
cd dindin-delivers

# Install dependencies
npm install

# Start the development server
npm start
```
