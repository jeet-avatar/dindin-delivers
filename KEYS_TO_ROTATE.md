## HOW TO GENERATE A NEW RANDOM SECRET

```bash
python3 -c "import secrets; print(secrets.token_hex(32))"
```

## CHECKR KEY ROTATION STEPS
1. Go to https://dashboard.checkr.com → Settings → API Keys
2. Create new key, copy it
3. On EC2: `nano /path/to/backend/.env` → update `CHECKR_API_KEY=<new>`
4. `pm2 restart all --update-env` (or ECS force-redeploy)
5. Revoke the old key in Checkr dashboard
