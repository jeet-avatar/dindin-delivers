**Part A — GAP-4: Fix self-delivery Mark Delivered (main_new.py)**

The existing `/erp/orders/{id}/delivered` alias at `main_new.py:15500` calls `order_delivered()` which requires a `Driver` object and checks `order.driver_id != driver.id`. Self-delivery orders have `driver_id=null`, so this fails with a 403.

Add a dedicated **`/erp/orders/{order_id}/vendor-delivered`** alias in `main_new.py` after the existing `vendor_arrived_alias` (inserted in Task 1). This alias:
1. Uses `Depends(require_vendor)` for auth
2. Verifies vendor owns the order (`order.vendor_id == vendor.id`)
3. Verifies this is a self-delivery order (`order.restaurant_will_deliver == True`)
4. Calls the `complete_vendor_delivery()` helper — OR directly reuses the same accounting logic

@app.post("/erp/orders/{order_id}/vendor-delivered")
async def vendor_delivered_alias(order_id: int, vendor: Vendor = Depends(require_vendor), db: Session = Depends(get_db)):
    """Alias for iOS Restaurant app self-delivery - mark order as delivered by restaurant
    Bypasses driver_id check — vendor owns the order and delivered it themselves.
    iOS calls: POST /erp/orders/{orderId}/vendor-delivered (NEW) or /erp/orders/{orderId}/delivered
    Backend: calls order_delivered_vendor() — a vendor-auth variant
    """
    order = db.query(Order).filter(Order.id == order_id).first()
    if not order:
        raise HTTPException(status_code=404, detail="Order not found")
    if order.vendor_id != vendor.id:
        raise HTTPException(status_code=403, detail="Not authorized for this order")
    if not getattr(order, 'restaurant_will_deliver', False):
        raise HTTPException(status_code=400, detail="Not a self-delivery order — use /delivered for driver-delivered orders")
