**Lifecycle stages to cover (left panel nodes, in order):**

1. **New Order Arrives** — `PENDING_RESTAURANT`
   - 3-minute acceptance countdown starts from `sent_to_restaurant_at`
   - Phone mockup: incoming order card with orange pulsing ring, countdown "2:45"

2. **Accept → Preparing** — `PENDING_RESTAURANT → PREPARING`
   - Proper path: `POST /erp/orders/{id}/restaurant-accept` → KOT print + driver early notification
   - Bug path (current): `PUT /erp/orders/{id}/status?status=PREPARING` → bypasses KOT, no driver notification
   - Phone mockup: order card with "Preparing" badge

3. **Mark Ready** — `PREPARING → READY_FOR_PICKUP`
   - `PUT /erp/orders/{id}/status?status=READY_FOR_PICKUP`
   - Triggers `delivery_decision_sent_at` → 3-min delivery decision window starts
   - Phone mockup: green "Ready" badge, delivery decision prompt appears

4. **Delivery Decision** — `PENDING_DELIVERY_DECISION`
   - Two options: "Send to Driver Pool" (`POST /erp/orders/{id}/restaurant-decline-delivery`) or "I'll Deliver" (`POST /erp/orders/{id}/restaurant-accept-delivery`)
   - 3-minute window; timeout → `READY_FOR_PICKUP` (driver pool, no push sent — GAP-5)
   - Phone mockup: two-button card "Self-Deliver" vs "Driver Pool"

5. **Self-Delivery: Start Trip** — `RESTAURANT_WILL_DELIVER → OUT_FOR_DELIVERY`
   - `PUT /erp/orders/{id}/status?status=OUT_FOR_DELIVERY`
   - Phone mockup: "Start Delivery" swipe button

6. **Self-Delivery: In Transit → Arrived** — `OUT_FOR_DELIVERY`
   - `POST /erp/orders/{id}/vendor-arrived-at-delivery` — **RED: alias missing in main_new.py (GAP-2)**
   - Backend function `vendor_arrived_at_delivery` exists at `order_flow.py:4942`
   - Phone mockup: "I've Arrived at Customer" button with RED badge

7. **Self-Delivery: Mark Delivered** — `OUT_FOR_DELIVERY → PENDING_DELIVERY_PROOF → DELIVERED`
   - `POST /erp/orders/{id}/delivered` → ERP alias at `main_new.py:15500`
   - Auth mismatch: alias uses `require_any_auth`, but `order_delivered()` at `order_flow.py:3887` requires `Driver` object and checks `order.driver_id != driver.id` — fails for self-delivery (driver_id=null) — **RED (GAP-4)**
   - Phone mockup: camera sheet for delivery photo

8. **Driver Pool Path** — `READY_FOR_PICKUP → OUT_FOR_DELIVERY → DELIVERED`
   - Driver assigned, picks up, delivers via driver app
   - Phone mockup: "Waiting for Driver" card, then "Order Delivered" receipt

9. **Timeout / Rejection Paths**
   - Acceptance timeout (>3 min): `PENDING_RESTAURANT → RESTAURANT_TIMEOUT` + Stripe refund
   - Delivery decision timeout (>3 min): `PENDING_DELIVERY_DECISION → READY_FOR_PICKUP` + no push (GAP-5)
   - Restaurant decline: `PENDING_RESTAURANT → DECLINED_BY_RESTAURANT` + Stripe refund
   - Phone mockup: red "Order Timed Out" or "Order Declined" card
