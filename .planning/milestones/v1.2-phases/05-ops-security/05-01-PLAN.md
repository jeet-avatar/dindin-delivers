<task type="auto">
  <name>Task 2: Install pre-commit hook to block secret commits</name>
  <files>.git/hooks/pre-commit</files>
  <action>
    Create a lightweight shell-based pre-commit hook at `.git/hooks/pre-commit` (zero dependencies, immediate protection):

    ```bash
    #!/bin/sh
    # Pre-commit hook: Block commits containing secrets
    # Installed by Phase 05 Ops Security

    # Check staged changes (not already committed content)
    STAGED_DIFF=$(git diff --cached --diff-filter=d)

    if echo "$STAGED_DIFF" | grep -qE "(sk_live_[A-Za-z0-9]+|sk_test_[A-Za-z0-9]{20,}|AKIA[A-Z0-9]{16}|-----BEGIN.*PRIVATE KEY-----)"; then
        echo ""
        echo "ERROR: Potential secret detected in staged changes!"
        echo ""
        echo "Blocked patterns: Stripe live/test keys, AWS access keys, private keys"
        echo "Review your changes before committing."
        echo ""
        echo "If this is a false positive, commit with: git commit --no-verify"
        exit 1
    fi

    # Block .p8 files (App Store Connect keys)
    if git diff --cached --name-only | grep -q '\.p8$'; then
        echo ""
        echo "ERROR: .p8 file (App Store Connect key) detected in staged changes!"
        echo "These must NEVER be committed to git."
        exit 1
    fi

    # Block .env files with actual secrets (not .env.example or .env.staging)
    if git diff --cached --name-only | grep -qE '\.env$|\.env\.local$'; then
        echo ""
        echo "ERROR: .env file detected in staged changes!"
        echo "Use .env.example for templates. Never commit actual .env files."
        exit 1
    fi
    ```

    Make the hook executable: `chmod +x .git/hooks/pre-commit`

    NOTE: This hook is local-only (`.git/hooks/` is not tracked by git). It protects THIS clone only. For team-wide protection, the project would need `pre-commit` framework or GitHub's secret scanning (out of scope for this single-developer project).

    Do NOT use `--no-verify` flag detection (the regex check for sk_test_ requires 20+ chars to avoid matching the placeholder `sk_test_your_key_here` in stripe_integration.py).
  </action>
