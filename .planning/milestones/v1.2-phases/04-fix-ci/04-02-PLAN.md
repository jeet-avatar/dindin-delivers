**Fix 1: database.py line 18 -- change ENVIRONMENT default from "production" to empty string:**

Change line 18 from:
```python
_is_prod = os.getenv("ENVIRONMENT", "production").lower() in ("production", "prod")
```
To:
```python
_is_prod = os.getenv("ENVIRONMENT", "").lower() in ("production", "prod")
```

This ensures that when ENVIRONMENT is unset (CI default), the app does NOT add sslmode=require to PostgreSQL connections. Production ECS tasks explicitly set ENVIRONMENT=production in their task definition, so production behavior is unchanged.
