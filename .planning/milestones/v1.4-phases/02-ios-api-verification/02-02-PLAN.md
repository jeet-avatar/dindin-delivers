**Step 2: Map P2PAPIService function calls to backend routes**
For each P2PAPIService function called from the Driver app:
1. Find the function definition in P2PAPIService.swift
2. Extract the URL path it constructs
3. Verify the path exists in backend route registrations
4. Check HTTP method matches
5. Check auth: Driver functions should send `driverToken` and backend should use `Depends(require_driver)` or `Depends(require_any_auth)`
6. Check request body field names match backend parameter names
7. Check response model fields match backend response

**Step 3: Verify direct API calls**
For each direct URLRequest/URL construction in Driver app files:
1. Extract the URL path
2. Run `grep -rn "path/segment" apps/web/p2p-platform/backend/*.py` to confirm route exists
3. Check method, auth, body, response
