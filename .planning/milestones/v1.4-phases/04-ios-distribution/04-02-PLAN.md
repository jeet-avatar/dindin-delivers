Archive and upload each of the 3 iOS apps to TestFlight. Each app follows the same 2-step process: archive, then export+upload (ExportOptions.plist has `destination: upload` so exportArchive handles both).

**IMPORTANT RULES:**
- Use `-configuration Release` (NOT `-configuration Production`)
- Use `-workspace` paths (not `-project`)
- Use `-allowProvisioningUpdates` for automatic signing
- Use App Store Connect API key authentication (`-authenticationKeyPath`, `-authenticationKeyID`, `-authenticationKeyIssuerID`)
- Clean archive output directory first: `rm -rf /tmp/dollor-archives/ /tmp/dollor-ipas/`

**Customer App (build 1096):**
```bash
# Archive
xcodebuild archive \
  -workspace apps/ios/customer/eatfaircustomer.xcworkspace \
  -scheme eatfaircustomer -configuration Release \
  -archivePath /tmp/dollor-archives/customer.xcarchive \
  -destination 'generic/platform=iOS' -allowProvisioningUpdates

# Export + Upload (one step)
xcodebuild -exportArchive \
  -archivePath /tmp/dollor-archives/customer.xcarchive \
  -exportOptionsPlist apps/ios/customer/ExportOptions.plist \
  -exportPath /tmp/dollor-ipas/customer \
  -allowProvisioningUpdates \
  -authenticationKeyPath ~/.appstoreconnect/private_keys/AuthKey_9K626GB728.p8 \
  -authenticationKeyID 9K626GB728 \
  -authenticationKeyIssuerID 80d10e49-f379-462f-9668-5ea53016812e
```
