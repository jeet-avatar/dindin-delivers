8. Expose `window.cognitoAuth` with:
   - `async getSession()` — read localStorage, refresh if `expiresAt < now + 60s` margin.
   - `async requireSession()` — redirect to `LOGIN_URL?redirect=<encoded current path>` if no session.
   - `async signInWithMagicLink(email)` — POST `InitiateAuth { AuthFlow: 'CUSTOM_AUTH', ClientId, AuthParameters: { USERNAME: email } }`; stash `{email, session, challengeName, startedAt}` into `sessionStorage[SESSION_KEY]`; return `{challengeName: 'CUSTOM_CHALLENGE', email}`.
   - `async respondToChallenge(token, emailOverride?)` — POST `RespondToAuthChallenge { ChallengeName: 'CUSTOM_CHALLENGE', ClientId, Session, ChallengeResponses: { USERNAME, ANSWER: token } }`; write `{idToken, accessToken, refreshToken, expiresAt, email}` into `localStorage[STORAGE_KEY]`; clear `sessionStorage[SESSION_KEY]`.
   - `async refreshSession()` — POST `InitiateAuth { AuthFlow: 'REFRESH_TOKEN_AUTH', ClientId, AuthParameters: { REFRESH_TOKEN } }`; merge new IdToken+AccessToken into stored session (RefreshToken stays same).
   - `async signOut()` — clear both storages, redirect to `LOGIN_URL`.
