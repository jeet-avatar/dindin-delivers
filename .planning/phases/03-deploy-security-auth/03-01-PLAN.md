**Option B: Manual deploy via AWS CLI**

Run from `apps/web/p2p-platform/backend/`:

1. Authenticate to ECR:
```bash
aws ecr get-login-password --region us-east-1 | docker login --username AWS --password-stdin 134607809447.dkr.ecr.us-east-1.amazonaws.com
```

2. Build the image (CRITICAL: must use `--target production` or it builds the test stage which runs pytest instead of uvicorn):
```bash
docker build --no-cache --target production -f Dockerfile.optimized --platform linux/amd64 -t 134607809447.dkr.ecr.us-east-1.amazonaws.com/dollor-api:security-auth-staging -t 134607809447.dkr.ecr.us-east-1.amazonaws.com/dollor-api:staging-latest .
```

3. Push to ECR:
```bash
docker push 134607809447.dkr.ecr.us-east-1.amazonaws.com/dollor-api:security-auth-staging
docker push 134607809447.dkr.ecr.us-east-1.amazonaws.com/dollor-api:staging-latest
```

4. Download current staging task-def, update image, register new revision:
```bash
aws ecs describe-task-definition --task-definition dollor-api-staging --query 'taskDefinition' > /tmp/staging-task-def.json
jq 'del(.taskDefinitionArn, .revision, .status, .requiresAttributes, .compatibilities, .registeredAt, .registeredBy)' /tmp/staging-task-def.json > /tmp/clean-staging-task-def.json
jq '.containerDefinitions[0].image = "134607809447.dkr.ecr.us-east-1.amazonaws.com/dollor-api:security-auth-staging"' /tmp/clean-staging-task-def.json > /tmp/new-staging-task-def.json
aws ecs register-task-definition --cli-input-json file:///tmp/new-staging-task-def.json
```

5. Update the ECS service to use the new task definition:
```bash
NEW_ARN=$(aws ecs describe-task-definition --task-definition dollor-api-staging --query 'taskDefinition.taskDefinitionArn' --output text)
aws ecs update-service --cluster dollor-production --service dollor-api-staging-service --task-definition "$NEW_ARN" --force-new-deployment
```

6. Wait for service stability (up to 10 minutes):
```bash
aws ecs wait services-stable --cluster dollor-production --services dollor-api-staging-service
```

**Rollback command (if needed):**
```bash

aws ecs update-service --cluster dollor-production --service dollor-api-staging-service --task-definition "dollor-api-staging:$PREV_REV" --force-new-deployment
```
