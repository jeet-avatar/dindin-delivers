## Decisions Made

- **NAT Gateway → NAT instance pivot (Option D).** Following Rule-4 architectural checkpoint in prior session. Account at 21/21 EIP quota. AWS support ticket (Option C) would block phase hours-days. Reclaiming live EIPs (Options A/B) was too risky without per-resource verification. NAT instance is $30/mo cheaper, requires no EIP, and the lower HA + maintenance burden is acceptable for the demo workload. Upgrade path back to NAT Gateway documented in script header + runbook.
- **t4g.nano on AL2023 ARM** for the NAT instance — cheapest Graviton instance ($3.07/mo on-demand), latest AMI for security, ARM compatible with all standard NAT tooling.
- **iptables MASQUERADE via user-data + rc.local persistence** — fewer moving parts than amzn-ami-vpc-nat (which only goes up to AL2). Inline script is small enough to inline; survives reboot via `/etc/rc.d/rc.local`.
- **SourceDestCheck disabled post-launch** because `aws ec2 run-instances` doesn't accept that flag inline — modify-instance-attribute after the instance reaches `running` state.
- **MapPublicIpOnLaunch=true on public-1a only** — minimal blast radius (only the AZ where the NAT instance lives). public-1b doesn't need it because nothing public will launch there.
