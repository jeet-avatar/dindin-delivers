# Phase 65.3 Plan 07: G2 Fix — Wrap Text-Walker substitute() in requestAnimationFrame

**One-line race fix across 7 already-refactored narrative ERP pages: deferred every text-walker substitute() invocation to requestAnimationFrame so it executes AFTER the data-loader's synchronous tbody re-render. Closes G2 (NarrativeSubstitutionRaceFix). 187 source-level audit violations preserved (intentional narrative fallback for tenants without data) but the rendered-DOM Turion-token leak on Solo Brands is now expected to drop from 187 to ≤7 after Plan 08 deploys.**

## Accomplishments

1. **Race condition closed at source.** Every text-walker substitute() invocation in the 7 in-scope files now defers to `requestAnimationFrame`. Both the synchronous `addEventListener('turion-data-ready', …)` path AND the microtask `__TURION_DATA_READY__.then(run)` path are now RAF-deferred — neither can fire before the data-loader's tbody re-render completes.
2. **Defensive RAF guard idiom** added inline at every wrap site: `typeof requestAnimationFrame === 'function' ? requestAnimationFrame(_x) : setTimeout(_x, 0)`. Survives headless / Node evaluation contexts.
3. **Zero audit regression** — source-code violation count for the 7 files held at 187 (and overall repo at 346) because the RAF wrap is pure JS plumbing with no Turion-token literals.
4. **All 7 modified script blocks parse cleanly** under `new Function(...)` JS parser — no syntax errors, no unbalanced braces/parens introduced by the wraps.

## Decisions Made

1. **RAF over setTimeout(0).** RAF is paint-aligned and batches with the browser's render cycle, ensuring substitution runs after layout but before paint. setTimeout(0) is a macrotask which can also schedule before paint but is less precisely aligned. Where the file already used setTimeout(0), I replaced it with RAF (strictly stronger).
2. **Defensive guard at every site.** Used `typeof requestAnimationFrame === 'function' ? requestAnimationFrame(_x) : setTimeout(_x, 0)` rather than bare `requestAnimationFrame(_x)`. This survives Playwright headless / Node parse / SSR contexts.
3. **Wrap BOTH paths, not just one.** The plan specifically called out `addEventListener('turion-data-ready', …)`, but the `__TURION_DATA_READY__.then(run)` microtask paths in 4 of the 7 files race too. Wrapping both ensures the fix is complete regardless of which trigger fires first.
4. **Inside-the-listener body wrap for inline patterns.** For arena-bom + arena-qms which had the substitute body directly inline in the listener (no named function), defined an inline `_runX` function variable inside the listener and called it via RAF. Could have refactored to a named module-level function, but inline preserves variable closure over the existing `if (window.ECO_DATA…)` prelude that needs to mutate the local `ECO_DATA`/`NCR_DATA`/etc. before substitution.
5. **Left line 453 of netsuite-items.html alone.** That `addEventListener('turion-data-ready', () => render())` invokes the items-grid table render — that IS the data-loader-like re-render, NOT the substitute. The race fix is to defer the substitute, not the table render itself.
