## Decisions Made

1. **Dropped `Honeywell · Aerospace` from audit TOKENS.** The plan's canonical 25-list does not include it. The narrow 8-token audit had it (specifically to catch the `·` separator rendering artifact). Removing it keeps audit + snapshot in true lockstep. `Blue Canyon` (still in the list) covers the supplier-name leak class.
2. **`Honeywell · Aerospace` still listed in smoke harness's `SB_FORBIDDEN` narrow set** for backwards-compat with Plan 08 baselines. Both narrow and wide smoke sets include it; only audit TOKENS array drops it. Plans 10 and 11 should be aware that the smoke narrow set is 8 tokens, but the audit + snapshot canonical lockstep is 25.
3. **Fail-OPEN over fail-CLOSED for the shim.** When `tenant.slug` is missing, the element is KEPT. Rationale: Turion is the established baseline; never destroy content on a transient API failure. Plan 10 still has a real gate — it just only triggers when we're CERTAIN the tenant is not Turion.
4. **Standalone `/tmp/compute-pre-expansion.mjs` for the artifact.** The plan suggested either an inline `node -e "…"` with shell substitution OR a standalone script. The shell-substitution approach is brittle (escaping `$` inside JS inside heredoc inside bash); standalone script parses `TOKENS_IN_DOM` directly from the source via regex. The standalone script is not committed (one-shot tool).
