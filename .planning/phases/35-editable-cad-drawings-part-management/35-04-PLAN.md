Create `satellite/svg-editor.js` — a plain `<script>` IIFE (no imports, no bundler), ~400-600 LOC, exposing `window.svgEditor = { open(svgString, { onSave, onCancel }) }`. Requirements:

- `open(svgString, {onSave, onCancel})`: build a full-screen modal overlay (`createElement`, appended to `document.body`) with a toolbar (Select / Add rect / Add line / Add circle / Add ellipse / Add polyline / Add text / Delete / Undo / Redo / Revert-to-generated [a callback the caller can disable] / Save / Cancel) and a canvas area. Parse `svgString` via `new DOMParser().parseFromString(svgString, 'image/svg+xml')`; if `doc.querySelector('parsererror')` → fall back to a `<textarea>` pre-filled with the raw `svgString` (Save = the textarea value). Otherwise mount `doc.documentElement` (the `<svg>`) into the canvas area; ensure it has a sensible `width`/`height`/`viewBox` for editing (if missing, derive from `getBBox()`).

- Editing model (work on the LIVE SVG DOM, not a model):
  - **Select:** `svgEl.addEventListener('pointerdown', e => { sel = e.target.closest('rect,circle,ellipse,line,polyline,polygon,path,text'); if (sel && !sel.closest('.__editor-ui')) drawHandles(sel); else { sel=null; clearHandles(); } })`. Clicking empty space deselects.
  - **Move:** pointerdown on the selected element → track pointermove deltas → update a `transform="translate(dx,dy)"` on `sel` (uniform; SVG round-trips it). pointerup commits a snapshot.
  - **Resize:** an 8-handle bounding box (4 corners + 4 edge midpoints) drawn from `sel.getBBox()` (the SVG must be rendered, not `display:none` — known gotcha). Dragging a handle applies a scale via a `transform` matrix (or directly rewrites geometry — translate+scale via `transform` is simplest). Re-draw the handles after.
  - **Rotate:** one handle above the bbox center; drag → `transform="rotate(deg, cx, cy)"` (compose with any existing translate/scale into one `transform` attr or stack `<g>` wrappers — stacking is simplest).
  - **Delete:** `Delete`/`Backspace` key OR the toolbar Delete button → `sel.remove()`; clear handles; snapshot.
  - **Edit text:** double-click a `<text>` → an inline `<input>` overlay (or `prompt()`) → set `sel.textContent`; snapshot.
  - **Add primitive:** the toolbar buttons set a "pending tool"; the next click-drag on the canvas creates the element via `document.createElementNS('http://www.w3.org/2000/svg', tag)` with sensible defaults (a fill/stroke from the existing palette if discoverable, else `#666`), appended to the root `<svg>` (or to the first `<g>` if one exists); snapshot.
  - **Undo/redo:** after every committed mutation, push `serialize()` onto `undoStack` (cap ~50, clear `redoStack`). `undo()` pops, pushes current onto `redoStack`, re-parses the popped string and replaces the canvas SVG (re-wire pointer handlers on the new `<svg>`). `redo()` symmetric.
  - **Editor UI isolation:** keep ALL handles/overlay/marquee elements in a `<g class="__editor-ui">` appended to the canvas SVG; `serialize()` clones the SVG, removes `.__editor-ui`, and returns `new XMLSerializer().serializeToString(clone)`.

- **Save:** call `onSave(serialize())`, then close the modal (the caller does the PATCH + re-render). **Cancel / Esc / overlay-click:** call `onCancel?.()` and close. **Revert-to-generated:** if the caller passed an `onRevert` callback (35-05 will), show it as a button that calls `onRevert()` and closes (the caller does the regenerate POST + reload); if not passed, omit the button.

- ALL wiring via `addEventListener` — ZERO inline `onclick=` attributes (the button audit fails on those). Use `textContent`, never `innerHTML` with user/SVG data. Guard double-injection: `if (window.svgEditor) return;` at the top.

`node --check satellite/svg-editor.js` must pass.
