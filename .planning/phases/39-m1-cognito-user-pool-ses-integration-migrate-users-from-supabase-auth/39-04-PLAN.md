**Step 2 — Extract nonce from CloudWatch logs:**
The Create-Auth-Challenge Lambda intentionally logs the nonce (per Plan 39-02 Task 1 — `console.log('[create-auth-challenge] nonce=' + nonce)`) so operators can run the smoke test without inbox access.

```bash
# Wait for log propagation (Lambda → CloudWatch can lag a few seconds)
sleep 5

LOG_GROUP=/aws/lambda/zietra-cognito-create-auth-challenge
# Find latest log stream
LATEST_STREAM=$(aws logs describe-log-streams --log-group-name "$LOG_GROUP" --order-by LastEventTime --descending --max-items 1 --region us-east-1 --query 'logStreams[0].logStreamName' --output text)
echo "Reading $LATEST_STREAM"

# Fetch the nonce from the latest events (filter the past 60s)
SINCE_MS=$(( ($(date +%s) - 60) * 1000 ))
NONCE=$(aws logs filter-log-events --log-group-name "$LOG_GROUP" --start-time "$SINCE_MS" --filter-pattern '[create-auth-challenge] nonce=' --region us-east-1 --query 'events[-1].message' --output text | grep -oE 'nonce=[A-Za-z0-9_-]+' | tail -1 | cut -d= -f2)

test -n "$NONCE" || { echo "FAIL: could not extract nonce from CloudWatch"; exit 1; }
```

```bash
PAYLOAD_B64=$(echo "$ID_TOKEN" | cut -d. -f2)
# Pad with = to a multiple of 4
PAD=$(( (4 - ${#PAYLOAD_B64} % 4) % 4 ))
PADDED="${PAYLOAD_B64}$(printf '=%.0s' $(seq 1 $PAD))"
CLAIMS=$(echo "$PADDED" | tr '_-' '/+' | base64 -d 2>/dev/null)
echo "$CLAIMS" | python3 -m json.tool > /tmp/cognito-claims.json
cat /tmp/cognito-claims.json

import json, sys
```

### Phase 40 high-level architecture (research-grade outline)

`backend/src/secrets.ts` extension:
- Load Supabase JWKS PEM at cold start (existing, leave as-is).
- ALSO load Cognito JWKS via `fetch('https://cognito-idp.us-east-1.amazonaws.com/<POOL_ID>/.well-known/jwks.json')` at cold start.
- Convert Cognito JWKS keys to PEMs via `crypto.createPublicKey({ format: 'jwk', key })` — same pattern as Phase 38's Supabase JWKS-to-PEM.
- Cache pool_id + client_id + region in module scope.

`backend/src/middleware/auth.ts` extension (dual-issuer):
- Pre-decode JWT header (no signature check) to read `iss` claim.
- If `iss === Cognito issuer` → `jwt.verify(token, cognitoPem, { algorithms: ['RS256'] })`.
- Else if `iss === Supabase issuer (https://lbpkbpfwdpnwlccmlfxn.supabase.co/auth/v1)` → existing ES256 path.
- Else → 401 invalid issuer.

Both sub-apps (`turion-satellite-api` + `turion-demo-api`) get the same change.
