## Decisions Made

1. **Strict deletion order** (Pitfall 5): shrink the 3 auth pages FIRST → delete Supabase lib files SECOND → uninstall npm dep THIRD. Reverse order would have left dangling imports and broken the intermediate build.
2. **APP_LOGIN = `/erp-login.html`** (not `/login`) — matches the Phase-38 ERP shell that already serves `requireAuth()` for all 96 ERP routes. One login page for all modules.
3. **Stripe checkout deferred** — Base tier renders `<button disabled title="Stripe checkout coming soon">` instead of routing to a broken `/signup`. No fake checkout flow.
4. **Removed fabricated testimonial** ("Priya Krishnan, COO · Harbor Labs, 8% → 31% reply rate") per global rule `no_unverified_assertions_in_demos`. Replaced with positioning copy: "One tenant. One bill. 13 modules of a Fortune-500 ERP."
5. **Sitemap dynamic-import uses try/catch** so 58-01 (where `src/data/modules.ts` doesn't exist yet) doesn't crash. 58-02/03 just drop the data files in place and the script picks them up automatically. No tsx/ts-node toolchain change needed.
6. **`/login /signup /dashboard` intentionally OMITTED from sitemap** — they're noindex redirects to app.zietra.com; indexing them creates duplicate-content + UX confusion.
7. **Footer Blog/Careers/Press dropped** — pages don't exist yet, better to ship 0 dead links than 4. Easy to re-add in a later phase once content is written.
