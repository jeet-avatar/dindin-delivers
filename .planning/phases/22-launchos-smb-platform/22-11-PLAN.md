**Gross margin verification (LOS-11):**

Document the calculation from spec §7, verified against actual API costs:

```
Growth tier: $149/mo revenue

Cost verification (80% light / 20% medium user blend per spec §7):
- Anthropic: 0.8 * $1 + 0.2 * $4 = $0.80 + $0.80 = $1.60 avg
- Remotion: 0.8 * $0.50 + 0.2 * $1.50 = $0.40 + $0.30 = $0.70 avg (self-hosted CPU)
- ElevenLabs: 0.8 * $0.40 + 0.2 * $1 = $0.32 + $0.20 = $0.52 avg
- WebRTC: 0.8 * $0.30 + 0.2 * $0.90 = $0.24 + $0.18 = $0.42 avg
- Email SES: 0.8 * $0.20 + 0.2 * $0.50 = $0.16 + $0.10 = $0.26 avg
- Social APIs: $0.20 (shared Twitter/X cost)
- Stripe fee: 2.9% * $149 + $0.30 = $4.32 + $0.30 = $4.62
TOTAL: $1.60 + $0.70 + $0.52 + $0.42 + $0.26 + $0.20 + $4.62 = $8.32 avg

Growth margin: ($149 - $8.32) / $149 = $140.68 / $149 = 94.4% gross margin
EXCEEDS $18/user/month target (actual avg cost: $8.32)
PASS: LOS-11 verified
```
