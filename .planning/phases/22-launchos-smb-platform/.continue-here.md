#### Render approach
SocialFlowVideo takes these props:
```typescript
{
  voiceover_url: string,       // file:// path to pre-generated mp3
  bgm_url: string,             // background music URL
  subtitle_segments: Array<{ text: string; start: number; end: number }>,
  scene_descriptors: Array<{
    template: string,          // one of the 15 above
    headline: string,
    subtext?: string,
    accent_color: string,
    transition_out: 'cross_fade' | 'flash' | 'zoom_out' | 'cut' | 'none',
    icon?: string,
  }>,
  voiceover_duration_seconds: number,
}
```

MAX_SCENE_FRAMES = 150 (5 seconds at 30fps). For 20s video: 5 scenes × 4s each.
