<objective>
Build the LaunchOS Entitlement Service — a new lightweight Node.js/TypeScript microservice that enforces per-tier quotas across all LaunchOS apps and handles unified Stripe billing. Then deploy it to ECS Fargate via CI/CD so Wave 2 connectors can call it at runtime.

Purpose: This is the foundational cross-app layer. Every other connector (video generation, meeting sync, AI bot) calls this service before executing quota-limited actions. Without it, there are no usage caps and no billing enforcement.

Output:
- New Express/TypeScript app at `apps/launchos-entitlement/`
- Three endpoints: `/entitlements/check`, `/entitlements/consume`, `/entitlements/usage`
- Stripe Checkout + webhook handler for 3 LaunchOS price IDs
- Redis-backed counters with monthly TTL auto-reset
- Dockerfile for ECS Fargate deployment on `dollor-production` cluster
- CI/CD GitHub Actions workflow — deploys to ECS (never manual docker/aws commands)
- Live ECS service URL available for Wave 2 plans
</objective>

**src/middleware/auth.ts** — Verify incoming requests from sub-apps using a shared HMAC secret:
```typescript
import jwt from 'jsonwebtoken';
export function requireLaunchOSToken(req, res, next) {
  const token = req.headers['x-launchos-token'];
  if (!token) return res.status(401).json({ error: 'Missing x-launchos-token' });
  try {
    const payload = jwt.verify(token as string, process.env.LAUNCHOS_JWT_SECRET!);
    (req as any).launchosUser = payload;
    next();
  } catch {
    res.status(401).json({ error: 'Invalid token' });
  }
}
```

**src/routes/entitlements.ts** — Three endpoints backed by Redis (ioredis connecting to `dollor-production` Redis ElastiCache at `dollor-redis.uwva3u.0001.use1.cache.amazonaws.com:6379`):

`POST /entitlements/check` — body: `{ launchos_user_id, action, quantity }`. Get tier from Redis key `launchos:tier:{user_id}` (default: `starter`). Get current month usage from `launchos:usage:{user_id}:{action}:{YYYY-MM}`. Compare against tier limit. Return 200 `{ allowed: true, remaining: N, limit: N }` or 402 `{ allowed: false, tier, limit, used, upgrade_url: "https://techcloudpro.com/launchos#pricing" }`.

`POST /entitlements/consume` — body: `{ launchos_user_id, action, quantity }`. Atomically INCRBY the monthly counter key. Set TTL of 33 days (2851200 seconds) on first write (use `SET ... NX EX` pattern). Return `{ consumed: true, new_total: N }`.

`GET /entitlements/usage/:user_id` — Return all action counters for current month + tier limits. Used by dashboard.

**src/index.ts** — Wire up Express app on `PORT` env var (default 4000). Mount `requireLaunchOSToken` on all `/entitlements/*` routes. Health check at `GET /health` (no auth, returns `{ ok: true }`).

```typescript
  mode: 'subscription',
  payment_method_types: ['card'],
  line_items: [{ price: PRICE_ID_FOR_TIER, quantity: 1 }],
  customer_email: email,
  subscription_data: { trial_period_days: 30 },
  success_url: `${process.env.FRONTEND_URL}/launchos/dashboard?subscribed=true`,

return { url: session.url };
```

`POST /stripe/webhook` — Raw body (mount before `express.json()` on this route). Verify with `stripe.webhooks.constructEvent`. Idempotency set (in-memory, cap at 10K — same as `stripe_routes.py:128-130`). Handle:
- `checkout.session.completed` → set `launchos:tier:{metadata.launchos_user_id}` to `metadata.tier` in Redis (no TTL — persists until cancelled)
- `invoice.payment_succeeded` → confirm tier still active
- `customer.subscription.deleted` → delete tier key from Redis (returns user to starter)
- `invoice.payment_failed` → log warning (do not downgrade immediately — grace period)

`POST /stripe/portal` — Create Stripe billing portal session for subscription management.

**Step 3: Create `.github/workflows/deploy-launchos-entitlement.yml`:**
```yaml
name: Deploy LaunchOS Entitlement Service

on:
  workflow_dispatch:
  push:
    paths:
      - 'apps/launchos-entitlement/**'
    branches:
      - main

env:
  AWS_REGION: us-east-1
  ECR_REPOSITORY: launchos-entitlement
  ECS_SERVICE: launchos-entitlement-service
  ECS_CLUSTER: dollor-production
  CONTAINER_NAME: launchos-entitlement

jobs:
  deploy:
    name: Build and Deploy
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Configure AWS credentials
        uses: aws-actions/configure-aws-credentials@v4
        with:
          aws-access-key-id: ${{ secrets.AWS_ACCESS_KEY_ID }}
          aws-secret-access-key: ${{ secrets.AWS_SECRET_ACCESS_KEY }}
          aws-region: ${{ env.AWS_REGION }}

      - name: Login to Amazon ECR
        id: login-ecr
        uses: aws-actions/amazon-ecr-login@v2

      - name: Build, tag, and push image to ECR
        id: build-image
        env:
          ECR_REGISTRY: ${{ steps.login-ecr.outputs.registry }}
          IMAGE_TAG: ${{ github.sha }}
        run: |
          docker build \
            -f apps/launchos-entitlement/Dockerfile \
            -t $ECR_REGISTRY/$ECR_REPOSITORY:$IMAGE_TAG \
            -t $ECR_REGISTRY/$ECR_REPOSITORY:latest \
            apps/launchos-entitlement/
          docker push $ECR_REGISTRY/$ECR_REPOSITORY:$IMAGE_TAG
          docker push $ECR_REGISTRY/$ECR_REPOSITORY:latest
          echo "image=$ECR_REGISTRY/$ECR_REPOSITORY:$IMAGE_TAG" >> $GITHUB_OUTPUT

      - name: Download task definition
        run: |
          aws ecs describe-task-definition \
            --task-definition launchos-entitlement \
            --query taskDefinition > task-definition.json

      - name: Update ECS task definition with new image
        id: task-def
        uses: aws-actions/amazon-ecs-render-task-definition@v1
        with:
          task-definition: task-definition.json
          container-name: ${{ env.CONTAINER_NAME }}
          image: ${{ steps.build-image.outputs.image }}

      - name: Deploy to ECS
        uses: aws-actions/amazon-ecs-deploy-task-definition@v1
        with:
          task-definition: ${{ steps.task-def.outputs.task-definition }}
          service: ${{ env.ECS_SERVICE }}
          cluster: ${{ env.ECS_CLUSTER }}
          wait-for-service-stability: true
```
