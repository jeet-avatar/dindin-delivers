    **Upload AAB bundles and submit for review:**

    For EACH of the 3 apps:

    1. Go to **Release > Production** (or **Testing > Internal testing** first if you prefer to test before production)
    2. Click **"Create new release"**
    3. Upload the AAB bundle:
       - Customer: `/Users/jeet/StudioProjects/eatfair-android/app/build/outputs/bundle/release/app-release.aab`

    4. Add release notes: "Initial release - food delivery and rideshare matchmaking platform"
    5. Review the release and click **"Start rollout to Production"** (100% rollout)

    **IMPORTANT NOTES:**
    - First upload MUST be done manually via Play Console (Fastlane cannot do first upload)
    - Play Console will show a review checklist -- all items (store listing, content rating, Data Safety, pricing) must be green
    - If any checklist items are red/incomplete, complete them before submitting
    - After submission, review typically takes 1-3 days for new developers (can be up to 7 days)

    **Recommended track strategy:**
    - If confident: Upload directly to **Production** track
    - If cautious: Upload to **Internal testing** first, verify installs work, then promote to Production
