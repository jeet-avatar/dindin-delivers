<task type="checkpoint:human-action" gate="blocking">
  <name>Task 2: Create all 3 apps in Play Console and enroll Play App Signing</name>
  <action>
    User creates all 3 apps in Google Play Console and configures Play App Signing. Claude cannot access the Play Console web UI.

    **Create all 3 apps in Google Play Console and configure Play App Signing:**

    For EACH of the 3 apps below, do the following steps:

    ---

    **App 1: Customer App**
    - Package name: `ai.dollor.customer`
    - Default language: English (United States)
    - App name: "Dollor - Food and Rides"
    - Free app

    **App 2: Driver App**
    - Package name: `ai.dollor.driver`
    - Default language: English (United States)
    - App name: "Dollor Driver"
    - Free app

    **App 3: Partner App**
    - Package name: `ai.dollor.partner`
    - Default language: English (United States)
    - App name: "Dollor Partner"
    - Free app

    ---

    **For EACH app, after creation:**

    1. Go to **Setup > App signing** (or it appears during first AAB upload)
    2. Choose **"Upload a key exported from Java KeyStore"**
    3. Download the PEPK tool from the page (or use the provided command)
    4. Run this command to export the key:
       ```bash
       java -jar pepk.jar \
         --keystore=/Users/jeet/StudioProjects/eatfair-android/dollor-release.jks \
         --alias=dollor \
         --output=output.zip \
         --include-cert \
         --encryptionkey=ENCRYPTION_KEY_FROM_PLAY_CONSOLE
       ```
       (The `ENCRYPTION_KEY_FROM_PLAY_CONSOLE` value is shown on the Play Console page)
    5. Upload the `output.zip` to Play Console
    6. This makes `dollor-release.jks` your **upload key** and Google manages the **app signing key**

    **Alternative (simpler):** During first AAB upload, Play Console offers to set up app signing automatically. If you upload the AAB first, it will use the AAB's signing certificate as the upload key. This is equivalent and acceptable.
  </action>
  <verify>User confirms all 3 apps exist in Play Console with Play App Signing configured.</verify>
