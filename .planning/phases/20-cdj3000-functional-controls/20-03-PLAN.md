**CUE button fix (currently at lines 314-317):**

The current code has THREE event handlers on the CUE button:
- `onClick={handleCue}` — sets cue (paused) or returns to cue (playing)
- `onMouseDown` — starts preview from cue (paused only)
- `onMouseUp` — ends preview, returns to cue

When paused, clicking fires BOTH onClick (setCuePoint) AND mouseDown (preview), causing the cue to be set and then immediately previewed.

**CDJ-3000 real behavior:**
- While PAUSED: short press = set cue point. Long press (hold) = preview from cue, release returns.
- While PLAYING: press = return to cue point and pause.

**Fix approach — use a timer to distinguish tap from hold:**

1. Add refs for CUE button timing:
```typescript
const cueTimerRef = useRef<ReturnType<typeof setTimeout> | null>(null);
const cueHoldRef = useRef(false);
```

2. Replace the CUE button's event handlers (lines 314-317). Remove `onClick`, keep only `onMouseDown` and `onMouseUp`:

```typescript
<div style={S.btn('#FF8C00')}
  onMouseDown={(e) => {
    if (e.button !== 0) return;
    cueHoldRef.current = false;
    if (audio.isPlaying) {
      // Playing: return to cue immediately on press
      actions.returnToCue();
      return;
    }
    // Paused: start a timer — if held >150ms, it's a preview hold
    cueTimerRef.current = setTimeout(() => {
      cueHoldRef.current = true;
      actions.cuePreviw(); // start preview playback from cue
    }, 150);
  }}
  onMouseUp={() => {
    if (cueTimerRef.current) {
      clearTimeout(cueTimerRef.current);
      cueTimerRef.current = null;
    }
    if (cueHoldRef.current) {
      // Was a hold-preview — return to cue
      actions.cueRelease();
      cueHoldRef.current = false;
    } else if (!audio.isPlaying) {
      // Was a short tap while paused — set cue point
      actions.setCuePoint();
    }
  }}
  onMouseLeave={() => {
    // If mouse leaves while holding, treat as release
    if (cueHoldRef.current) {
      if (cueTimerRef.current) clearTimeout(cueTimerRef.current);
      actions.cueRelease();
      cueHoldRef.current = false;
    }
  }}
>CUE</div>
```
