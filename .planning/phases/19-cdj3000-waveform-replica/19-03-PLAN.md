**RGB Mode** (`wfStyle === 'rgb'`):
Three overlapping color channels, each mirrored from center independently:
```
Red channel (bass):  color #FF0000, height = (low / 255) * H * 0.85
Green channel (mid): color #00FF00, height = (mid / 255) * H * 0.85
Blue channel (high): color #0066FF, height = (high / 255) * H * 0.85
```
Draw order: Red first (back), then Green (middle), then Blue (front).
Each bar is mirrored from center. Use `globalAlpha = 0.7` for overlap transparency so all three colors are visible when overlapping.
Bar width: same 3px bars with 1px gap.

**BLUE Mode** (`wfStyle === 'blue'`):
Monochrome blue, single bar per column:
```
total = low + mid + high
amplitude = total / (255 * 3)  // 0-1
barHeight = amplitude * H * 0.85
```
Color varies by frequency content (shade of blue):
```
// More high = lighter/brighter blue, more low = deeper/darker blue
highRatio = high / Math.max(total, 1)
r = Math.round(highRatio * 80)        // slight cyan tint for highs
g = Math.round(highRatio * 120)       // more cyan for treble
b = Math.round(150 + amplitude * 105) // base blue 150-255
```
Draw mirrored from center, same bar width as other modes.
