**2. 3Band Color Blend Algorithm** — For each waveform column with `{low, mid, high}` values (0-255):
```
const BAND_BLUE   = { r: 0x00, g: 0x55, b: 0xE1 };  // #0055E1 — bass
const BAND_ORANGE = { r: 0xFF, g: 0xA6, b: 0x00 };  // #FFA600 — mid
const BAND_WHITE  = { r: 0xFF, g: 0xFF, b: 0xFF };  // #FFFFFF — high

total = low + mid + high
if (total === 0) skip column
wl = low / total;  wm = mid / total;  wh = high / total;
r = Math.round(BAND_BLUE.r * wl + BAND_ORANGE.r * wm + BAND_WHITE.r * wh);
g = Math.round(BAND_BLUE.g * wl + BAND_ORANGE.g * wm + BAND_WHITE.g * wh);
b = Math.round(BAND_BLUE.b * wl + BAND_ORANGE.b * wm + BAND_WHITE.b * wh);
brightness = Math.min(1, total / 400);  // scale by energy
```

**3. Mirrored Bars from Center** — Bars grow BOTH up and down from the horizontal center line (H/2):

```
// Draw top half: from center upward

// Draw bottom half: from center downward
ctx.fillRect(x, H/2, barW, halfBar);
```
