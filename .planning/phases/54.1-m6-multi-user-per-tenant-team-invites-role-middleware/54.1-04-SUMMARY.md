## Decisions Made

1. **Phase 54.6 is the NEW next phase, not 54.2.** Per user pivot in execution-context prompt: Enterprise Hardening Starter Pack (VPC + RDS Proxy + WAF + GuardDuty + Security Hub + zietra.com/security trust page) sits between 54.1 and original M3/RLS work. CHECKPOINT.md and SUMMARY both reflect this; ROADMAP.md insertion of 54.6 entry is deferred to the 54.6 planner.

2. **vitest version resolved to ^2.1.9 (vs satellite's ^2.1.0).** npm's caret-resolution picked the latest 2.1.x at install time. Both satisfy `^2.1.0`, so the Rule 4 parity is preserved at major.minor; the patch drift is npm's normal behavior and not worth pinning.

3. **vi.hoisted() pattern used for shared mock state** (cognitoSendMock + roleRef). The first run of invite-flow.test.ts failed with "Cannot access 'cognitoSendMock' before initialization" because `vi.mock` is hoisted above all top-level `const` declarations. `vi.hoisted()` is the canonical Vitest fix and is now baked into the test file with an inline comment for future readers.

4. **roleRef as single-element array, not a let-variable.** vi.hoisted requires that the returned binding be referenced via destructure; a `let CURRENT_ROLE` outside of vi.hoisted gets re-declared each time the module is re-evaluated. The array pattern (`roleRef[0]`) gives a stable hoisted reference that tests can mutate.

5. **Test 7 of tenant-users.test.ts reads migration 026 SQL file directly.** Pins the FK ON DELETE CASCADE contract to the actual migration source — if anyone weakens the cascade clause, this test fails loudly. Better than relying on a stale comment.

6. **Smoke matrix exit codes match 54.1-02 SUMMARY's documented behavior.** The plan's "expect 401" for `GET /api/team` (no headers) is actually 400 (tenantContext fires first per Phase 53). Confirmed both shapes (400 no-slug, 401 with-slug-no-bearer) as expected. Documented as a clarification, not a deviation.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] vi.mock hoisting captured uninitialized cognitoSendMock**
- **Found during:** Task 3, first run of invite-flow.test.ts
- **Issue:** `ReferenceError: Cannot access 'cognitoSendMock' before initialization` — vi.mock factory is hoisted above all top-level `const` declarations, so the `cognitoSendMock = vi.fn()` was undefined when the factory ran.
- **Fix:** Use `vi.hoisted()` pattern: `const { cognitoSendMock } = vi.hoisted(() => ({ cognitoSendMock: vi.fn() }))`. Same pattern applied to `roleRef`.
- **Files modified:** /Users/jeet/turion-space-demo/backend/tests/unit/invite-flow.test.ts
- **Commit:** `bf95f4d` (same task)
- **Verification:** Re-run → 12/12 tests pass in 36 ms.
