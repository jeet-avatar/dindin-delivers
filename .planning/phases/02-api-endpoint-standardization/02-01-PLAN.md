Android calls 5 financial endpoints that do not exist on the backend. These are called from actual Android screens (EarningsScreen, SettingsViewModel, PaymentSettingsScreen for vendor; driver balance/payout UI).

**Add 5 new endpoints to main_new.py:**

1. **GET /api/drivers/{driver_id}/balance** -- Returns the driver's available Stripe Connect balance. Implementation:
   - Add `Depends(require_driver)` for auth with ownership check (driver_id must match token)
   - Use `stripe.Account.retrieve(driver.stripe_account_id)` to get the balance if driver has Stripe Connect
   - If no Stripe account, return `{"success": true, "available_balance": 0, "pending_balance": 0, "currency": "usd"}`
   - If Stripe error, return the zero-balance response (graceful degradation)

2. **POST /api/drivers/{driver_id}/bank-account** -- Links a bank account via Stripe Connect. Implementation:
   - Accept body: `{"account_holder_name": str, "routing_number": str, "account_number": str}`
   - Add `Depends(require_driver)` with ownership check
   - Use `stripe.Account.create_external_account()` to add bank
   - Return `{"success": true, "bank_account_id": "...", "last4": "...", "bank_name": "..."}`
   - On error, raise HTTPException(400) with Stripe error detail

3. **POST /api/drivers/{driver_id}/payouts** -- Request a manual payout. Implementation:
   - Accept body: `{"amount": float, "payout_type": str}` (payout_type = "standard" or "instant")
   - Add `Depends(require_driver)` with ownership check
   - Use `stripe.Payout.create(amount=int(amount*100), currency="usd", metadata={"driver_id": driver_id})` on the connected account
   - Return `{"success": true, "payout_id": "...", "amount": amount, "status": "pending", "arrival_date": "..."}`

4. **POST /api/vendors/{vendor_id}/bank-account** -- Links a bank account for vendor payouts. Implementation:
   - Same pattern as driver bank-account but uses vendor's Stripe Connect account
   - Add `Depends(require_vendor)` with ownership check

5. **GET /api/erp/payouts/vendor/{vendor_id}** -- Get vendor payout info. Implementation:
   - Add `Depends(require_vendor)` with ownership check (or require_any_auth + admin override)
   - Return Stripe Connect balance + recent payouts list from the vendor's connected account
   - Graceful degradation if no Stripe account

**Pattern reference:** Look at existing Stripe Connect endpoints around line ~5150-5300 in main_new.py (driver Stripe create, onboarding, status, dashboard) for import patterns and error handling.

**Auth pattern:** Use the established pattern from Phase 01: `_auth_driver: Driver = Depends(require_driver)` then `if _auth_driver.id != driver_id: raise HTTPException(403, "Access denied")`

**Stripe import:** `stripe` is already imported in main_new.py. Use `stripe.Account.retrieve()`, `stripe.Payout.create()`, etc. For connected accounts, pass `stripe_account=driver.stripe_account_id` parameter.

Add all 5 paths to the middleware public path allowlist ONLY if they should be public (they should NOT -- they all require auth). So do NOT add them to the allowlist.
