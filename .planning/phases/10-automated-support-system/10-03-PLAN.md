    **Part A: Add support chat method to P2PAPIService.swift**

    Add a new method for the AI text chat endpoint:

    `sendSupportChatMessage(message: String, completion: @escaping (Result<String, Error>) -> Void)`:
    - POST `/api/support/chat`
    - Body: `{"message": "user's question"}`
    - If customer token is available, include it in Authorization header for context
    - Parse response: `{"success": true, "response": "AI reply text"}`
    - Return the AI response string on success

    **Part B: Create LiveChatView.swift**

    A simple chat interface for text-based AI support. Follow the same UI patterns as DriverChatView but simpler (no polling needed -- this is request/response, not real-time):

    - Properties: None required (standalone support chat)
    - State:
      ```swift
      @State private var messages: [(String, Bool)] = [] // (text, isFromUser)
      @State private var messageText = ""
      @State private var isLoading = false
      ```
    - UI structure:
      - NavigationView title: "Live Chat"
      - ScrollView with message bubbles (user messages right-aligned blue, AI messages left-aligned gray)
      - Initial AI greeting message: "Hi! I'm Dollor AI Support. How can I help you today?"
      - Text input bar at bottom with TextField and send button
      - Loading indicator when waiting for AI response
    - Send flow:
      1. User taps send
      2. Append user message to messages array
      3. Set isLoading = true
      4. Call `P2PAPIService.shared.sendSupportChatMessage(message:)`
      5. On success: append AI response to messages array, isLoading = false
      6. On error: append error message "Sorry, I couldn't process that. Please try again.", isLoading = false
    - Quick suggestion buttons at the top (before any messages): "Order status", "Ride issue", "Account help", "Refund request"
    - Tapping a suggestion fills it into messageText and auto-sends
